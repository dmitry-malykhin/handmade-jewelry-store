Проверить текущий диф по чек-листу проекта. По каждому пункту дать вердикт
и, если есть нарушение, показать файл, строку и как исправить.

## TypeScript и структура

- Нет типа `any`
- Пропсы через `interface`, `type` только для юнионов и примитивов
- Общие типы в `packages/shared/src/index.ts`
- Компоненты не ходят в API напрямую, только через TanStack Query
- Нет `useEffect` для загрузки данных
- `'use client'` только там, где нужны состояние, события или браузерные API
- Логика вынесена из `page.tsx` в `lib/`, `_components/`, `components/features/`

## Именование

- Имена говорят, что хранят или делают: `formatPriceInDollars`, `cartItems`, `handleAddToCart`
- В коллбэках массивов доменные имена, не `i`, `x`, `item`
- Селекторы Zustand через `(state) =>`
- `response`, а не `res`. `error`, а не `e` или `err`
- Именованные обработчики не заменены на инлайновые стрелки

## Разметка и доступность

- Семантические теги: `article`, `ul role="list"`, `nav`, `main`, `aside`, `figure`, `data`
- Нет `div` с `onClick`, нет `a` без `href`
- У изображений товаров непустой описательный `alt`
- `next/image` вместо `img`, явные `width` и `height`, `priority` у первой картинки

## Темы и локализация

- Только семантические токены: `bg-background`, `text-foreground`, `border-border`
- Нет сырых цветов вида `text-gray-900`
- Ни одной захардкоженной строки, всё через `useTranslations` или `getTranslations`
- Новые ключи добавлены в `en.json`, `ru.json`, `es.json`
- Переведены также `aria-label`, `placeholder`, `title`

## SEO

- Уникальные `title` и `description`
- `canonical` на динамических страницах, OpenGraph везде
- На карточках товара `ProductJsonLd`
- URL по `slug`, не по `id`
- Каталог и карточка товара — серверные компоненты

## Комментарии

- Комментарии только там, где логика неочевидна, и только про «почему»
- Нет комментариев, пересказывающих код

## Тесты

- Для нового кода написаны тесты нужного уровня
- Названия тестов самоописательные
