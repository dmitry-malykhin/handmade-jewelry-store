---
description: Выдать готовое сообщение коммита без выполнения git-команд
argument-hint: [номер issue]
---

Показать список изменённых файлов, затем выдать **одну строку** сообщения
коммита в блоке кода — чтобы работала кнопка копирования.

Формат Conventional Commits, номер issue в конце:

```
feat: add product card component #12
```

Правила:

- Никаких команд `git add`, `git commit`, `git push`, никаких HEREDOC
- Только сама строка сообщения, ничего вокруг неё внутри блока
- Пользователь коммитит сам через панель Source Control в VS Code

Если номер issue не передан — определить его из имени текущей ветки.
