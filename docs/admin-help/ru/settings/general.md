# Настройки магазина

## Зачем эта страница

Глобальные настройки магазина. Три секции на одной странице, у каждой
своя кнопка **Сохранить** (сохраняется только своя секция, не вся страница).

1. **Общие** — название магазина, слоган, контакты
2. **Соцсети** — ссылки на профили (показываются в футере)
3. **Доставка и возвраты** — возвратная политика, сроки доставки, порог
   бесплатной доставки

Настройки хранятся одной записью в БД (singleton, `id = "default"`) и
читаются на каждом запросе витрины — изменения видны на публичной
стороне моментально.

---

## Секция 1 — Общие

### Название магазина
- **Зачем**: Имя в header витрины, page titles, email-подписи, чеки.
- **Как заполнять**: 1–120 символов. Обязательно.
- **Эффект**: Меняется на всех публичных поверхностях при следующей
  загрузке страницы. SEO `<title>` теги пересобираются при ISR-revalidate.

### Слоган
- **Зачем**: Короткое предложение под лого / в hero на главной.
- **Как заполнять**: ≤ 200 символов. Необязательно но желательно.
- **Рекомендация**: Чёткое value prop. Например
  `Украшения ручной работы из чешского хрусталя`.

### Email для контактов
- **Зачем**: Публичный ящик на странице контактов витрины и в футере.
- **Как заполнять**: Валидный email или пусто.
- **Эффект**: Это адрес, на который покупатели пишут. Используй тот,
  что реально читаешь.

### Email поддержки
- **Зачем**: Куда уходят order-related уведомления. Может совпадать с
  контактным; разделение когда объём поддержки требует отдельного ящика.
- **Как заполнять**: Валидный email или пусто.

## Секция 2 — Соцсети

Все 4 поля принимают URL `https://` или пусто. Пустое — иконка не
показывается в футере.

### Instagram URL
- **Зачем**: Ссылка в футер на Instagram-профиль.
- **Формат**: `https://instagram.com/yourhandle`

### Pinterest URL
- **Зачем**: Ссылка в футер. Pinterest — high-intent канал для ювелирки,
  стоит указать если есть пины.
- **Формат**: `https://pinterest.com/yourhandle`

### Facebook URL
- **Зачем**: Ссылка на Facebook-страницу.
- **Формат**: `https://facebook.com/yourpage`

### TikTok URL
- **Зачем**: Ссылка на TikTok-профиль.
- **Формат**: `https://tiktok.com/@yourhandle`

**Эффект для всех 4**: Пустое поле полностью убирает иконку из футера
(никаких битых ссылок).

## Секция 3 — Доставка и возвраты

### Окно возврата (дни)
- **Зачем**: Срок возврата для покупателя. Виден на карточках товаров и
  странице правил.
- **Как заполнять**: 0–365 дней.
- **Рекомендация**: `30`. Индустриальный стандарт для handmade ювелирки.

### Порог бесплатной доставки (центы)
- **Зачем**: Сумма заказа, выше которой доставка бесплатна.
- **Как заполнять**: В центах (`7500` = $75).
- **Эффект**: Ниже порога — покупатель платит за доставку; выше или
  равно — бесплатно. Прогресс-бар в корзине.
- **Рекомендация**: 2–3x среднего чека.

### Доставка от (дни)
- **Зачем**: Оптимистичный край окна доставки. Показывается как
  «доставка X–Y дней» на карточке и чекауте.
- **Как заполнять**: 0–60. Должно быть ≤ «Доставка до».

### Доставка до (дни)
- **Зачем**: Пессимистичный край окна — что ты ответишь если
  спросят «сколько максимум?».
- **Как заполнять**: 0–60. Должно быть ≥ «Доставка от».
- **Рекомендация**: Уже для in-stock (например `3–7`), шире для
  made-to-order (например `10–21`).

## Типичные сценарии

**Начальная настройка после запуска**
Общие → название, слоган, оба email → сохранить. Соцсети → заполни
профили которые реально ведёшь → сохранить. Доставка → возврат `30`,
порог `7500`, доставка `3–7` для in-stock базового кейса → сохранить.

**Переименование бренда**
Общие → обнови название → сохранить. Проверь header витрины — должен
обновиться в пределах нескольких секунд.

**Праздничная задержка доставки**
Доставка → подними «до» с `7` до `14` → сохранить. Сроки на витрине
обновляются везде моментально.

## Подводные камни

- **Каждая секция сохраняется отдельно.** Если правишь и Общие и
  Доставку в одном визите — нажми обе кнопки **Сохранить**.
- **Откатить нельзя** — last write wins. Для смены brand identity
  сделай скриншот предыдущих значений до правки.
- **`мин > макс` для дней доставки блокируется** клиентской валидацией.
- **Чтобы убрать иконку соцсети — оставь URL пустым.** Per-icon toggle
  нет.
- **Валюта**: цены всегда хранятся в USD-центах
  (см. `docs/09_MULTI_CURRENCY.md`). На странице настроек выбора валюты
  нет.
