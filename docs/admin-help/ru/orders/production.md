# Производство

## Зачем эта страница

Мастерская — заказы с изделиями типа «Под заказ» или «Единственный
экземпляр». Эти позиции изготавливаются **после** оплаты, поэтому
очередь показывает что сейчас на верстаке и насколько близок дедлайн.

Дедлайн рассчитывается на чекауте от `Дней производства` товара —
см. колонку **Дедлайн** ниже.

Используй страницу чтобы:

- Видеть что делать следующим (по дедлайну)
- Менять статус изделия по мере работы
- Хранить свободные заметки по заказу (например «нужен синий лунный
  камень, заказан в понедельник»)

## Поля и элементы управления

### Дедлайн
- **Зачем**: Дней до обещанной даты готовности.
- **Цветовая кодировка**:
  - Красный badge **Просрочено** — дата прошла
  - Красный badge **Сегодня** — дедлайн сегодня
  - Янтарный — 1–3 дня
  - Зелёный — 4+ дня
- **Как считается**: `productionDeadlineAt` заказа (выставленный на чекауте
  по самому медленному изделию) минус «сейчас», округлённое до полных дней.

### Статус (по строке)
- **Зачем**: Где этот заказ в производстве.
- **Значения**:
  - **В очереди** — не начат
  - **В работе** — активно изготавливается
  - **Готово к отправке** — закончен, ждёт упаковки
- **Как заполнять**: Выбор из dropdown → моментальная запись.
- **Эффект**: `Готово к отправке` **не отправляет автоматически** —
  ты по-прежнему идёшь в детали заказа, сохраняешь трекинг и переводишь
  заказ в `Отправлен`.
- **Рекомендуемый поток**: В очереди → В работе (когда взял инструмент)
  → Готово к отправке (изделие закончено, сфотографировано, упаковано).

### Заметки
- **Зачем**: Свободные заметки по заказу. До 500 символов.
- **Как заполнять**: Печатай → Enter или клик вне → автосохранение.
- **Эффект**: Видны только админу. Покупатель не увидит.
- **Применение**: Учёт заказанных материалов, блокеры, спец-просьбы
  покупателя.

## Типичные сценарии

**Утренняя проверка мастерской**
Сортируй визуально по дедлайну (таблица уже отсортирована) → работай
сверху вниз. Всё красное — в первую очередь.

**Материал заказан, ждать неделю**
Статус остаётся `В очереди`. Заметка: «жду 6мм розовый кварц от
поставщика, ETA пт.». Перепроверь в пятницу.

**Закончил изделие**
Статус → `Готово к отправке`. Открой деталь заказа, сохрани трекинг,
переведи заказ в `Отправлен`. Строка в очереди остаётся `Готово к
отправке`, пока заказ не выйдет из «под заказ»-территории.

## Подводные камни

- **Строка появляется только если в заказе есть хоть одна позиция «Под
  заказ».** Чистые in-stock заказы сюда не попадают.
- **Колонка «Изделия» считает только позиции под заказ** — не общий
  размер корзины.
- **Дедлайн 0 или отрицательный** не флагается покупателю и не шлёт
  email. Это твой визуальный cue; решение по задержке принимаешь сам
  (возврат vs предупредить и продолжить).
- **Заметки не видны на странице заказа покупателя** — они внутренние.
- **Заказ отменён в середине производства**: строка остаётся пока ты
  не удалишь позиции «под заказ» через управление заказом. Inline-
  механизма скрыть строку пока нет.
