# Заказы

## Зачем эта страница

Источник правды по всем покупкам. Каждый успешный Stripe-чекаут попадает
сюда и движется по линейному state machine до **Доставлен** (или
**Возврат** / **Отменён**).

Используй страницу чтобы:

- Видеть входящие заказы одним взглядом
- Двигать заказ по жизненному циклу (Оплачен → В обработке → Отправлен → Доставлен)
- Фильтровать по статусу для приоритезации работы

Для работы с конкретным заказом (трекинг, возврат, полный адрес,
позиции) нажми **Открыть** — см. [Детали заказа](detail.md).

## Поля и элементы управления

### Фильтр по статусу
- **Зачем**: Сузить таблицу до одного статуса.
- **Как заполнять**: Выбор из выпадающего списка. `Все статусы` показывает всё.
- **Эффект**: Страница сбрасывается на 1, таблица перезагружается.
- **Рекомендация**: `Все статусы` для ежедневного обзора; `Оплачен`
  когда садишься за исполнение; `Отправлен` для контроля доставки.

### Колонка Статус (dropdown)
- **Зачем**: Клик на badge статуса → выбор следующего разрешённого.
- **Как заполнять**: Доступны только корректные переходы (см. ниже).
- **Эффект**: Моментальное сохранение. Покупателю сразу видно обновление.
  Откатить — переходом дальше или через возврат.

### Ссылка Открыть
- **Зачем**: Полная страница заказа с адресом, позициями, историей,
  трекингом и возвратами.

## State machine

Разрешённые переходы (whitelist из бэкенда):

```
Ожидает оплаты    → Оплачен, Отменён
Оплачен           → В обработке, Отменён
В обработке       → Отправлен, Отменён
Отправлен         → Доставлен
Доставлен         → Возврат, Частичный возврат
Отменён           → Возврат, Частичный возврат
Возврат           → (финальный)
Частичный возврат → (финальный)
```

`Ожидает оплаты → Оплачен` происходит автоматически через Stripe webhook
— вручную этот переход почти никогда не делаешь.

## Типичные сценарии

**Утренняя рутина**
Фильтр `Оплачен` → для каждой строки открой деталь → упакуй → сохрани
трек-номер → статус автоматически становится `Отправлен`.

**Покупатель написал что посылка пришла**
Найди заказ (фильтр `Отправлен` + поиск по email в деталях) → переведи
в `Доставлен`. На этом переходе начисляются лояльные баллы.

**Отмена неоплаченного заказа**
`Ожидает оплаты → Отменён` через dropdown в таблице. Платежа нет —
возврат не нужен.

## Подводные камни

- **Колонка ID заказа** показывает только последние 8 символов; полный
  UUID видно в URL после нажатия **Открыть**.
- **Колонка Покупатель** показывает `guestEmail` для гостевых заказов.
  Для зарегистрированных тоже email, но тип не виден — только в деталях.
- **Пагинация по 20.** В занятую неделю это несколько страниц — лучше
  фильтр, чем скролл.
