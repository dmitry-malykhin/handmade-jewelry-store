# Возвраты

## Зачем эта страница

Только для чтения — журнал всех проведённых возвратов. Одна строка на
каждый заказ с возвратом, новые сверху.

**Возвраты здесь не оформляются** — это делается на странице
[Детали заказа](detail.md) кнопкой **Оформить возврат**. Эта страница
нужна для:

- Сверки в бухгалтерии («сколько мы вернули в этом месяце?»)
- Анализа паттернов (много `Товар повреждён` по одному продукту →
  проблема с качеством)
- Быстрого поиска («какой возврат был по Klarna во вторник?»)

## Колонки

| Колонка | Значение |
|---|---|
| **Заказ** | Последние 8 символов, клик → детали заказа |
| **Клиент** | Email гостя; `—` для зарегистрированных (приватность) |
| **Возвращено** | Сумма в USD (сумма всех частичных возвратов по заказу) |
| **Причина** | Выбранная при оформлении возврата |
| **Дата** | Дата проведения возврата |
| **Статус** | `Возврат` (полный) или `Частичный возврат` |

## Типичные сценарии

**Ежемесячная сверка**
Открой страницу → суммируй колонку **Возвращено** → сверь с отчётом
о возвратах в Stripe Dashboard. Цифры должны совпадать до цента (Stripe
— источник правды; мы только зеркалируем).

**Анализ качества**
Мысленно отфильтруй строки `Товар повреждён` → открой детали заказа →
запиши SKU. Если 3+ возврата по одному SKU → переведи товар в архив
или пересмотри сборку.

**Поиск конкретного возврата**
Поиск по короткому ID заказа через Ctrl/Cmd+F в таблице (server-side
поиск на этой странице не реализован — она легковесная).

## Подводные камни

- **Запись появляется только после успешного возврата на Stripe.**
  Неудачные попытки сюда не попадают — смотри toast-уведомление на
  странице деталей заказа.
- **Пустая колонка Клиент** не означает гостя — это просто
  зарегистрированный пользователь (мы скрываем email здесь; полный
  доступ — в деталях заказа).
- **Несколько частичных возвратов по одному заказу** показываются как
  одна строка с суммированной величиной. Отдельные события возврата —
  в истории заказа.
