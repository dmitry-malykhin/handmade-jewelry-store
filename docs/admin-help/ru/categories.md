# Категории

## Зачем эта страница

Управление таксономией каталога — рубрики по которым покупатели
фильтруют товары на витрине (`Кольца`, `Колье`, `Браслеты`, …).

Каждый товар принадлежит **ровно одной** категории. Категории
отображаются в навигации витрины, breadcrumbs, JSON-LD товара. Слаг —
часть канонического URL: `/shop?categorySlug=rings`.

Используй страницу чтобы:

- Добавить новую категорию при запуске новой линии товаров
- Переименовать категорию (слаг автогенерируется если оставить пустым)
- Удалить категорию (только если пуста — см. «Подводные камни»)

## Поля и элементы управления

### Название
- **Зачем**: Человекочитаемая метка. Видна в навигации, breadcrumbs,
  фильтрах.
- **Как заполнять**: С заглавной, единственное или множественное —
  согласованно с существующими категориями. `Кольца`, не `кольцо` или
  `КОЛЬЦА`.
- **Эффект**: Видно покупателю. Обязательно.

### Слаг (необязательно в форме, генерируется автоматически)
- **Зачем**: URL-safe идентификатор. Используется в URL фильтра и SEO.
- **Как заполнять**: kebab-case, нижний регистр, без пробелов.
  `engagement-rings`, не `Engagement Rings`. Оставить пустым →
  автогенерация из названия.
- **Эффект**: **Изменение слага ломает все внешние ссылки** на эту
  категорию (поисковики, Pinterest, реклама). После публикации считай
  слаг неизменяемым, если не готов настроить redirect.
- **Рекомендация**: При первом сохранении дай сгенерироваться. Меняй
  только если слаг неочевиден.

### Колонка «Товары» (только чтение)
- **Зачем**: Сколько товаров сейчас в категории.
- **Эффект**: Категории с `> 0` товаров **нельзя удалить** — сначала
  перенеси или архивируй товары.

### Кнопка «Новая категория»
- **Зачем**: Открыть форму создания.
- **Как заполнять**: Название (обязательно) + слаг (необязательно). Submit.

### Действие «Редактировать» (карандаш)
- **Зачем**: Открыть форму редактирования.
- **Эффект**: Сохранение моментально применяется к живой категории.

### Действие «Удалить» (корзина)
- **Зачем**: Полное удаление категории.
- **Когда можно**: Только `Товары = 0`.
- **Эффект**: Безвозвратно. Категория исчезает с витрины сразу.

## Типичные сценарии

**Запуск новой линии — «Анклеты»**
**Новая категория** → Название `Анклеты` → слаг оставить пустым →
сохранить. Затем редактируй существующие товары и присваивай новую
категорию.

**Переименование «Кольца» в «Все кольца»**
Редактировать → Название `Все кольца` → **слаг оставить как `rings`**
чтобы существующие URL не сломались. Сохранить.

**Удаление снятой с продажи категории**
Перенеси все товары в другую категорию (редактируй каждый) → удали.

## Подводные камни

- **Две категории с одинаковым слагом не разрешены.** Бэкенд вернёт
  unique-constraint ошибку в виде toast.
- **Пустой список категорий** = сообщение «Категорий пока нет».
  Создай хотя бы одну до того как создавать товары.
- **Смена слага не создаёт редирект.** Известное ограничение —
  настраивай redirect в `next.config.js` вручную.
- **Иерархия не поддерживается** — нет parent/child. Подкатегорий нет.
