# Создание товара

## Зачем эта форма

Создаёт новую карточку товара. Сразу после сохранения товар появляется
в каталоге в статусе по умолчанию **Черновик** — покупатели его не
видят, пока ты не переключишь на **Активен**.

Заполняй внимательно: SEO-метаданные и качество карточки напрямую
влияют на органический трафик и конверсию.

## Разделы формы

1. **Основная информация** — название, описание, URL-слаг, артикул
2. **Цена и остатки** — цена, количество, тип наличия, дней производства
3. **Категория и материал**
4. **Размеры (необязательно)** — длина, ширина, высота, диаметр, вес, размер бусины
5. **Изображения** — drag-and-drop загрузка фото

---

## Раздел 1 — Основная информация

### Название
- **Зачем**: Заголовок карточки, `<h1>` на странице товара, основа SEO.
- **Как заполнять**: Конкретно и описательно. `Браслет «Северное сияние»
  из чешского хрусталя`, а не `Браслет №1`. До 200 символов.
- **Эффект**: Используется в SEO `<title>`, OpenGraph, JSON-LD,
  результатах Google Shopping.
- **Рекомендация**: Включай ключевое слово (тип украшения) + USP
  (материал / стиль / повод).

### Описание
- **Зачем**: Основной текст карточки + meta description для SEO.
- **Как заполнять**: 100–500 слов. Опиши: материал, размеры, повод,
  уход. Markdown не поддерживается — только обычный текст.
- **Эффект**: Влияет на ранжирование Google и решение покупателя.
- **Рекомендация**: 3–5 абзацев. Первый абзац — самое важное (попадает
  в meta description, ограничено 160 символами).

### URL-слаг
- **Зачем**: Часть URL: `/products/{slug}`. Канонический идентификатор.
- **Как заполнять**: Автогенерируется из названия (kebab-case,
  транслитерация, без спецсимволов). Меняй вручную только при
  необходимости.
- **Эффект**: **После публикации не меняй** — внешние ссылки сломаются.
- **Рекомендация**: Не трогай автогенерированное значение.

### Артикул (необязательно)
- **Зачем**: Внутренний идентификатор товара (SKU).
- **Как заполнять**: Любой формат, главное — уникальный. Например
  `BR-CRYSTAL-001`.
- **Эффект**: Отображается на странице товара, в счёте, в Google
  Shopping feed.

## Раздел 2 — Цена и остатки

### Цена (USD)
- **Зачем**: Цена в долларах. Хранится в центах, отображается
  покупателю в его валюте по курсу.
- **Как заполнять**: Десятичное число (например `49.99`). Минимум `0.01`.
- **Эффект**: Используется во всех страницах витрины, корзине,
  оформлении заказа, Stripe Checkout.

### Количество на складе
- **Зачем**: Сколько штук готово к отправке прямо сейчас.
- **Как заполнять**: Целое неотрицательное число.
- **Эффект**: `0` → товар показывается как «Распродано», корзина
  блокируется. Списывается автоматически при подтверждении заказа.

### Тип наличия
- **Зачем**: Как товар поставляется.
- **Значения**:
  - **В наличии** — готов к отправке, расходуется со склада
  - **Под заказ** — изготавливается после оплаты, требует
    `Дней производства`
  - **Единственный экземпляр** — `Количество = 1`, после продажи
    автоматически архивируется
- **Рекомендация**: Для бисера и серийных украшений — В наличии. Для
  именных и custom — Под заказ. Для арт-объектов — Единственный экземпляр.

### Дней производства
- **Зачем**: Сколько рабочих дней нужно для изготовления.
- **Когда обязательно**: Для типа **Под заказ** (≥ 1).
- **Как заполнять**: Целое число рабочих дней.
- **Эффект**: При оформлении заказа от даты заказа +
  `Дней производства` рассчитывается дедлайн для очереди
  [Производство](../orders/production.md).

## Раздел 3 — Категория и материал

### Категория
- **Зачем**: Куда товар попадает в каталоге.
- **Как заполнять**: Выбор из существующих категорий. Если нужной нет —
  сначала создай в разделе [Категории](../categories.md).

### Материал (необязательно)
- **Зачем**: Из чего сделан. Влияет на SEO + JSON-LD `Product.material`.
- **Как заполнять**: Свободный текст. Например `Чешский хрусталь`,
  `Серебро 925`, `Натуральный жемчуг`.
- **Эффект**: Показывается в карточке покупателю; индексируется
  поисковиками.

---

## Раздел 4 — Размеры (необязательно)

Хранятся в метрической системе, отображаются покупателям из США в
дюймах автоматически.

- **Длина (см)** / **Ширина (см)** / **Высота (см)** / **Диаметр (см)**
- **Вес (граммы)** — для серёг и колец критичен
- **Размер бусины (мм)** — для браслетов и ожерелий

**Рекомендация**: Заполни как минимум вес и хотя бы один размер. Помогает
SEO и снижает % возвратов.

---

## Раздел 5 — Изображения

- **Зачем**: Главное, что видит покупатель. Конверсия напрямую зависит
  от качества фото.
- **Как заполнять**: Drag-and-drop или клик. До 10 изображений, JPG/PNG/WebP,
  до 5 МБ каждое. Первое фото = главное (видно в листингах).
- **Рекомендация**: Минимум 3 фото — на белом фоне (главное), в lifestyle
  (на руке/шее), макро (детали). Все вертикально (3:4), 1500×2000 px.

## Типичные сценарии

**Серийный браслет в наличии — 5 штук**
Тип: В наличии · Остаток: 5 · Дней производства: оставить пустым.

**Кольцо на заказ с гравировкой**
Тип: Под заказ · Остаток: 0 (игнорируется) · Дней производства: 7.

**Уникальное колье из найденного камня**
Тип: Единственный экземпляр · Остаток: 1 (форсируется при сохранении).

## Подводные камни

- **Слаг после публикации не меняй** — внешние ссылки сломаются.
- **Цена в долларах, хранится в центах** — все валютные конверсии
  делает система автоматически.
- **«Дней производства» без типа «Под заказ» игнорируется** — это
  ожидаемое поведение.
