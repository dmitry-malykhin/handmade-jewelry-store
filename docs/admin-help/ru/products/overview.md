# Товары

## Зачем эта страница

Каталог всех товаров магазина. Здесь они появляются вне зависимости от
статуса — активные, черновики и архив. Покупатели на витрине видят только
со статусом **Активен**.

Используй страницу чтобы:

- Создать новый товар (кнопка **Новый товар** справа сверху)
- Найти товар по названию или артикулу
- Изменить статус (Активен / Черновик / Архив)
- Открыть форму редактирования
- Удалить товар, который никогда не продавался

## Поля и элементы управления

### Поиск по названию или артикулу
- **Зачем**: Найти конкретный товар.
- **Как заполнять**: Подстрока названия или артикула. Без регистра.
  Debounce 300 мс.
- **Эффект**: Сбрасывает страницу пагинации на 1, перезагружает таблицу.

### Фильтр по статусу
- **Зачем**: Сузить список до товаров с одним статусом.
- **Значения**: `Все статусы`, `Активен`, `Черновик`, `Архив`.
- **Рекомендация**: `Активен` — для ежедневной работы; `Черновик` —
  когда ищешь незавершённые карточки; `Архив` — для аудита.

### Колонка Статус (drop-down)
- **Зачем**: Сменить статус прямо из таблицы — клик на badge → выбор.
- **Эффект**: Моментальное сохранение. Покупатели увидят изменение
  после ISR-revalidate (до 1 часа) или сразу при следующем заходе.

### Действие «Редактировать»
- **Зачем**: Открыть полную форму редактирования.
- **Эффект**: Переход на отдельную страницу.

### Действие «Удалить»
- **Зачем**: Полное удаление товара.
- **Когда**: Только для товаров, которые никогда не продавались.
  Иначе — переведи в **Архив**, чтобы сохранить историю заказов.

## Колонки таблицы

| Колонка | Значение |
|---|---|
| **Название** | Текст товара + ссылка на edit |
| **Статус** | Активен / Черновик / Архив (клик → dropdown) |
| **Цена** | В USD, форматировано как $X.XX |
| **Остаток** | Числовой остаток (для in-stock) или `—` (для under-order) |
| **Артикул** | SKU или `—` |
| **Создан** | Дата создания |

## Типичные сценарии

**Создание нового товара**
Кнопка **Новый товар** → форма создания → заполни обязательные поля →
**Создать товар**. См. [Создание товара](create.md).

**Снять товар с продажи на время**
Кликни статус → **Сменить на Черновик**. Покупатели больше не увидят,
SEO-страница вернёт 410 Gone (со временем).

**Распродан финально**
Кликни статус → **Сменить на Архив**. История заказов сохраняется,
карточка скрыта из публичного каталога.

## Подводные камни

- **Удалять можно только товары без истории.** Если был хотя бы один
  заказ — кнопка удаления вернёт ошибку. Используй **Архив**.
- **Изменение слага после публикации ломает внешние ссылки** (Google
  Shopping, Pinterest, ads). Меняй только если готов настроить redirect.
- **ISR на каталоге = 1 час** — изменения статуса/цены могут отображаться
  с задержкой до часа на публичных страницах.
