# Склад

## Зачем эта страница

Контроль остатков по каталогу. Две функции, которых нет в обычной
странице **Товары**:

1. **Алерты low-stock** — товары с остатком ≤ заданного порога
   подсвечиваются красным badge.
2. **Inline-редактирование остатка** — клик на число → редактирование
   без захода в форму товара.

В sidebar ссылка **Склад** имеет красный счётчик-badge, если хотя бы
один товар в наличии ниже порога. Обновляется каждые 2 минуты (или сразу
после ручного изменения остатка здесь).

## Поля и элементы управления

### Алерт когда остаток ≤
- **Зачем**: Порог для low-stock алертов. По умолчанию `3`.
- **Как заполнять**: Целое число, обычно 1–10.
- **Эффект**: Sidebar badge считает товары с остатком ≤ этого значения.
  Слишком высокий — будет постоянно мигать; слишком низкий — узнаешь
  о нехватке поздно.
- **Рекомендация**: `3` для серийных украшений, `1` для медленно-двигающихся.

### Только low stock (переключатель)
- **Зачем**: Фильтрует таблицу до товаров с алертом.
- **Когда включать**: При вопросе «что мне сейчас нужно сделать?».

### Колонка Остаток (inline edit)
- **Зачем**: Клик на число → открывается input → новое значение →
  Enter или клик вне = сохранить. Escape = отмена.
- **Эффект**: Сохранение без подтверждения. Sidebar badge обновляется
  моментально.

## Что считается «low stock»

Только товары с типом **В наличии**. Товары **Под заказ** и
**Единственный экземпляр** исключены — для них `0` это нормальное
состояние.

## Типичные сценарии

**Ежедневная проверка остатков**
Открой страницу, посмотри на sidebar badge. Если `0` — всё в порядке.
Иначе включи **Только low stock** и обнови остатки после физического
пересчёта.

**Подбор порога**
После активных выходных закончились 3 товара. Либо снижай порог (меньше
алертов), либо приучи себя реагировать сразу когда появляется badge.

## Подводные камни

- **Остаток 0 у товара в наличии** — флагается (порог `<=`). Реши:
  пополнить или перевести в **Архив**.
- **Смена типа после публикации** — переключение с «В наличии» на «Под
  заказ» автоматически убирает товар из учёта.
