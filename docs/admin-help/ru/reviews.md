# Отзывы

## Зачем эта страница

Модерация всех отзывов покупателей. Здесь три действия:

1. **Одобрить** новые отзывы — после этого они появляются на странице товара.
2. **Скрыть** спам, оскорбления или нерелевантные отзывы.
3. **Ответить публично** от лица продавца — ответ показывается с отступом
   под отзывом покупателя.

Покупатели видят только **Одобренные** отзывы. Средние по товару
(`avgRating`, `reviewCount`) считаются только по одобренным — скрытие
5-звёздочного отзыва моментально снижает среднее.

## Поля и элементы управления

### Фильтр Статус
- Значения: `Все статусы`, `Ожидает`, `Одобрен`, `Скрыт`.
- Новые отзывы создаются со статусом **Ожидает** — на страницу товара
  они не попадают, пока ты не одобришь.

### Фильтр Оценка
- От 1 до 5 звёзд. Полезно для приоритизации низких оценок.

### Кнопки Одобрить / Скрыть
- По одной на строку. Кнопка текущего статуса скрыта — видны только
  осмысленные переходы.
- Эффект: моментальный. Средние по товару пересчитываются в той же
  транзакции.

### Ответить
- Inline textarea до 2000 символов.
- Превью показывает как ответ будет выглядеть на странице товара.
- Сохранение проставляет `sellerRepliedAt`. Повторное редактирование
  обновляет то же поле — истории версий нет.
- Ответ **не зависит** от статуса отзыва. Можно подготовить ответ на
  Ожидающий отзыв и потом его одобрить.

## Типичные сценарии

**Пришёл новый отзыв**
Фильтр `Ожидает` → читаем комментарий → Одобрить если осмысленный,
Скрыть если спам.

**Негативный отзыв на индивидуальный заказ**
Одобрить — другие покупатели увидят что критика не скрывается →
Ответить с контекстом («Мы вернули деньги, ещё раз приносим извинения»).
Публичный ответ показывает прозрачность.

**Поиск спама**
Фильтр `Ожидает` + визуальная сортировка по красным флагам (5 звёзд
без комментария от нового аккаунта, одинаковый текст для разных
товаров). Скрыть.

## Подводные камни

- **Скрытие ранее одобренного отзыва** убирает его со страницы товара
  и из `avgRating` моментально.
- **Повторное одобрение скрытого отзыва** возвращает его в среднее.
- **Истории версий ответа нет** — last save wins. Думай перед
  редактированием опубликованного ответа.
- **Email отзывающегося виден здесь, но публично маскируется** как
  «Jane d.» на странице товара.
