# Начало работы

## Зачем нужна Панель администратора

Это рабочее место владельца магазина. Отсюда ты управляешь товарами,
заказами, клиентами, промокодами и настройками магазина. Покупатели сюда
не попадают — только пользователи с ролью `ADMIN`.

Главное правило: всё, что меняешь здесь, **сразу видно покупателям**
(на ISR — в течение часа на каталоге, моментально на странице
оформления заказа). Деплой не нужен.

## С чего начать

1. **Настройки → Общие** — название магазина, слоган, контактный email.
2. **Категории** — создай хотя бы одну (например, `Кольца`), иначе товар
   некуда добавлять.
3. **Товары** — добавь первый товар. Минимум: название, цена, категория,
   1 фото.
4. Проверь публичную страницу магазина — товар должен появиться.

## Структура разделов

- **Дашборд** — KPI: выручка, заказы, средний чек, график выручки.
- **Товары** — каталог. Создание, редактирование, статусы.
- **Заказы** — все продажи. Смена статуса, трекинг, возвраты.
- **Возвраты** — журнал всех проведённых возвратов (только чтение).
- **Производство** — очередь изделий «под заказ» с дедлайнами.
- **Склад** — остатки в наличии с алертами на low stock.
- **Клиенты** — зарегистрированные пользователи + их LTV.
- **Категории** — таксономия каталога (название + слаг).
- **Промокоды** — коды скидок (% или фикс. сумма).
- **Настройки** — название магазина, email-ы, соцсети, окно доставки.

## Подсказки в каждом разделе

В правом верхнем углу любой страницы админки — кнопка `?`. Нажми её
(или клавишу `?` на клавиатуре) — откроется справка по текущей странице
с описанием полей, типичными сценариями и подводными камнями.

## Чего здесь нет (пока)

- Редактирование данных клиента — только клиент сам через свой кабинет
- Объёмная выгрузка в CSV — пока вручную через БД
- Уведомления в реальном времени о новых заказах — приходят на email
