# Клиенты

## Зачем эта страница

Список зарегистрированных клиентов с метриками для retention (количество
заказов, LTV, дата последнего заказа).

Гости **сюда не попадают** — гостевые заказы привязаны только к самому
заказу, не к клиенту. Чтобы найти гостя, ищи по email на странице
[Заказы](../orders/overview.md).

Используй страницу чтобы:

- Найти VIP по LTV
- Найти ушедших клиентов (нет заказов > N месяцев) для win-back кампаний
- Открыть профиль одного клиента и увидеть всю историю

## Поля и элементы управления

### Поиск по email
- **Зачем**: Найти клиента по подстроке email.
- **Как заполнять**: Любая часть email. Без регистра. Debounce 300 мс.
- **Эффект**: Страница сбрасывается на 1, таблица перезагружается.
- **Совет**: Поиск по домену (`@gmail.com`) для аудита проблем доставки
  у конкретного провайдера.

### Колонки

| Колонка | Значение |
|---|---|
| **Email** | Клик → профиль клиента |
| **Зарегистрирован** | Дата создания аккаунта |
| **Заказов** | Количество заказов в любом не-CANCELLED статусе |
| **LTV** | Lifetime value в USD — оплаченные заказы минус возвраты |
| **Последний заказ** | Дата последнего заказа или `—` |

### Пагинация
По 20 на странице. **Назад** / **Вперёд**. Прыжка на страницу нет —
это намеренно, поиск работает лучше скролла.

## Типичные сценарии

**Связь с VIP**
Сортируй визуально по LTV (таблица отсортирована по LTV) → первая
страница = топ-клиенты. Экспорт пока вручную (кнопки CSV нет).

**Win-back таргетинг**
Смотри **Последний заказ** — любой кто молчит >90 дней — кандидат на
письмо «мы скучаем». Сверь с сегментом в Klaviyo.

**Клиент спросил «сколько я потратил?»**
Открой профиль кликом по email → поле **LTV**.

## Подводные камни

- **LTV исключает заказы CANCELLED и REFUNDED.** Для частичных
  возвратов сумма возврата вычитается из вклада заказа.
- **Счётчики лояльности / wishlist здесь не показаны** — они в
  профиле.
- **Поиск только по полю email.** По имени поиск не работает.
